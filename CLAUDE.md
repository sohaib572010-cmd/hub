# Hub — agent instructions

Before making any change, read:

1. `PRD.md`: the full product and technical specification (architecture, every file, data model, routes, design system, change recipes).
2. `GUIDELINES.md`: mandatory code, security and design rules.

Hard requirements:

- Production-quality, secure, readable code only. No prototypes or placeholders.
- Keep the existing design. No emojis or unprofessional styling.
- Run `npm run typecheck` before committing.
- Update `PRD.md` (including its Changelog) in the same commit as any addition or modification to the site.
